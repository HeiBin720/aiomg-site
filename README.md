静态官网发布目录，面向 Cloudflare Pages 部署。

## 发布设置

- Framework preset: None
- Build command: 留空
- Build output directory: `.`
- Production branch: `main`
- Custom domain: `www.aiomg.vip`

- `/` 首页
- `/features.html` 功能介绍
